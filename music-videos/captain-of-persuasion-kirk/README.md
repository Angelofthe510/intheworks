# Captain of Persuasion / Kirk

Focused Kirk candidate collection gathered from the broader local `kirk` archive.

## Local inventory

- 18 PNG bridge and close-up portraits explicitly named for Captain Kirk
- 1 OBJ model

These are **review candidates**, not approved production assets. Unrelated Spock, Guardian, leisure-suit, and ice-world material in the source folder was intentionally excluded.

The website publishes a representative subset for team review; the complete focused collection and model remain in the local project archive.
