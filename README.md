# Yesterday's Son — Project Dashboard

Web-published production dashboard for **Yesterday's Son: The Loneliest Man**, **A Lonely Opera**, and their companion music videos.

The public pages contain optimized previews and review media. The complete working production package is consolidated under `project-files/yesterdays-son/`, including bibles, continuity, scripts, recovered chat material, music records, trackers, and source attachments.

Start with `yesterdays-son/index.html` for the unified project home or `project-files/yesterdays-son/README.md` for the production vault.
