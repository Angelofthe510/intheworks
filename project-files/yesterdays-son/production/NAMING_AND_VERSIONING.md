# Naming and Versioning

## Pattern

YS-[TYPE]-[NNN]_[Short-Descriptor]_v[NN].[ext]

Type codes: CHR character, LOC location, PRP prop, VEH vehicle, FX effect, SC scene, SH shot, MUS music, AUD audio, MKT marketing, DOC document, DEL delivery, REF reference.

## Rules

- IDs never change when titles change.
- Use ASCII filenames, hyphens inside descriptors, underscores between fields.
- v01 is the first saved version; increment for meaningful revision.
- Add status in the register, not the filename.
- Date-stamped exports may append _YYYY-MM-DD after version.
- Do not use final, final2, new, latest, or approved in filenames.

## Folder states

working contains editable sources; review contains review exports; approved contains current approved masters; superseded contains replaced versions. Registers remain the authority for status.
