# Read Me First

## Purpose

This package turns the production into a traceable studio system. The Markdown files are the canonical written record; the workbooks are operational views for tracking many records.

## Current assumptions

- Working title: Yesterday's Son: The Loneliest Man.
- Format: multimedia production combining story, music, still imagery, animation/video, and campaign materials.
- The linked public project page is a reference point, not automatically a source of canon.
- Story specifics not supplied in this package are marked TBD rather than invented.

## First production session

1. Confirm title, logline, format, target runtime, audience, and release plan in the Production Bible.
2. Complete the premise, emotional thesis, acts, scenes, and ending in the Story Bible.
3. Enter principal characters into the Character Bible and Character Register.
4. Create scene and shot IDs before generating final visuals.
5. Import known assets into the Asset Register and mark rights/provenance.
6. Name a decision owner for canon, creative approval, technical approval, and release.

## Status vocabulary

Use: Idea, Draft, In Review, Approved, In Production, Blocked, Superseded, Archived, Released.

## Approval gate

An item is Approved only when its creative intent, canon fit, technical fitness, provenance/rights, and intended uses are recorded. Released means it has actually been published or delivered.
