5. Promote an asset to approved only after creative, continuity, technical, and rights review.

## Operating principles

- Canon before convenience.
- One stable ID per asset, character, scene, shot, cue, and deliverable.
- Source files and exports are both retained, but never confused.
- Every approved item has an owner, version, status, rights note, and usage record.
- Dates use YYYY-MM-DD; versions use v01, v02, and so on.

## Naming convention

Use PROJECT-TYPE-NNN_SHORT-DESCRIPTOR_vNN.ext, for example YS-CHR-003_Guardian-Turnaround_v03.png or YS-SH-010_Threshold-Reveal_v02.mov. See production/NAMING_AND_VERSIONING.md.
